# Guardião Gamer — app do responsável

Android e Windows (iPhone previsto, ainda não testado). Veja o [README principal](../README.md) e [docs/CONFIGURAR-FIREBASE.md](../../docs/CONFIGURAR-FIREBASE.md).

- `lib/screens/login_screen.dart`: criar conta e entrar.
- `lib/screens/devices_screen.dart` e `add_device_sheet.dart`: aparelhos e código de pareamento.
- `lib/screens/device_screen.dart` e `rule_sheet.dart`: apps do aparelho, limite diário e bloqueio.
